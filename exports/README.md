# Siva Gayathri Tours & Travels — Master Tour Packages Export

This directory contains the complete, uncompressed, 100% data export of all tour packages and related operational models from the enterprise ERP database.

---

## 📁 Master Excel Workbook
- **File:** `Sivagayathiri_Tour_Packages_Master.xlsx` (8.57 MB)
- **Format:** Microsoft Excel (.xlsx), OpenDocument & Google Sheets compatible.
- **Styling:** Deep Navy `#1E3A8A` executive headers, frozen header panes, INR currency formatting (`₹#,##0.00`), integer formatting, Segoe UI typography, and column widths auto-proportioned for high readability.

### How to Import to Google Sheets:
1. Open Google Sheets (`sheets.google.com`).
2. Click **File** -> **Import** -> **Upload**.
3. Drag and drop any of the `.csv` files or the master `.xlsx` workbook.
4. Select **Replace current sheet** or **Create new spreadsheet** -> Click **Import data**.
